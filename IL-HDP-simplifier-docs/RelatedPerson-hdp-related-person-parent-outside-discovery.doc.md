# Active Parent Relationship Outside Dependent Discovery

This example preserves an active parent relationship after the dependent has passed the applicable legal age for discovery.

The record keeps `active=true` and the parent code. The `hmo-dependent-discovery` tag is absent, so the record cannot establish discovery eligibility. See the [dependent-discovery guidance](https://simplifier.net/hdp-il/ILHDPDependentDiscoveryRelatedPerson) for the reuse and withdrawal rules.
